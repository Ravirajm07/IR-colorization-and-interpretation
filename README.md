# IR WARRIORS MVP

**AI-Based Infrared Satellite Image Enhancement and RGB Colorization for Improved Object Interpretation**

A production-minded research MVP for **IR enhancement and RGB translation** from Landsat 8/9 Collection 2 Level-2 imagery. It aligns `ST_B10` with the visible `SR_B4/SR_B3/SR_B2` bands, removes QA-contaminated pixels, trains a Pix2PixHD-inspired model, evaluates only real held-out predictions, reconstructs georeferenced mosaics, and serves results through FastAPI and a GIS-style Streamlit dashboard.

## Scientific Scope

- Thermal input: `ST_B10`, scaled as `DN * 0.00341802 + 149.0` Kelvin.
- RGB target: `SR_B4`, `SR_B3`, `SR_B2`, scaled as `DN * 0.0000275 - 0.2` reflectance.
- Invalid pixels: QA_PIXEL bits 0-5 (fill, dilated cloud, cirrus, cloud, cloud shadow, snow).
- Alignment: all optical and QA bands are reprojected onto the ST_B10 grid.
- Split policy: complete scenes, never random patches, are assigned to train/validation/test.
- Generated colors are learned estimates, not observed visible reflectance.
- Landsat resolution does not support reliable vehicle-level detection.
- This project makes no true super-resolution claim. SwinIR and SegFormer are planned enhancements, not implemented capabilities.

## Implemented

- Extracted scene, Landsat ZIP, individual thermal GeoTIFF, and PNG demo inputs
- Safe ZIP extraction, file-size/type checks, clear validation errors, and persistent job IDs
- Collection 2 scaling, QA masking, cross-grid reprojection, physical normalization, and NoData handling
- Pune district selection from common Maharashtra shapefile fields, clipping, reprojection, and overlay
- 256-pixel patch generation with configurable stride, validity threshold, affine/CRS manifest, and scene-level splits
- Paired Albumentations, PyTorch Dataset/DataLoader, residual generator, two-scale PatchGAN, LSGAN/L1/feature/VGG losses
- CUDA, AMP, LR decay, early stopping, TensorBoard, best/latest checkpoints, CSV history, and resume
- PSNR, SSIM, MAE, RMSE, LPIPS, FID, inference timing, comparisons, and difference heatmaps
- Overlap-averaged RGB/ground-truth GeoTIFF mosaics and PNG previews
- FastAPI background jobs, Streamlit dashboard, CSV/PDF reports, Docker Compose, and pytest

Metrics are never seeded or hardcoded. LPIPS/FID return **Metric unavailable** with a reason if their dependencies, model weights, or sample count are insufficient.

## Local Installation

Python 3.11 is recommended. GDAL-compatible Rasterio/GeoPandas wheels are required.

```bash
cd ir-warriors-mvp
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
copy .env.example .env   # Windows; use: cp .env.example .env
pytest -q
```

Start the two services:

```bash
uvicorn app.main:app --reload --port 8000
streamlit run frontend/streamlit_app.py --server.port 8501
```

Open `http://localhost:8501`; API documentation is at `http://localhost:8000/docs`.

## Dataset Layout

Place each extracted scene in its own directory. A paired scene requires:

```text
LC08_..._ST_B10.TIF
LC08_..._SR_B2.TIF
LC08_..._SR_B3.TIF
LC08_..._SR_B4.TIF
LC08_..._QA_PIXEL.TIF
LC08_..._MTL.txt or LC08_..._MTL.json
```

Optional `SR_B5` and `SR_B6` are discovered but not required by the baseline. Put a Maharashtra districts shapefile (including its `.dbf`, `.shx`, `.prj`) under `data/boundaries/`; accepted district fields are `district`, `DISTRICT`, `DIST_NAME`, `NAME`, and `dtname`.

Acquire Landsat Collection 2 Level-2 scenes from USGS EarthExplorer or an equivalent official catalog. The repository contains no fabricated satellite scenes.

## Prepare, Train, Evaluate

At least three scenes are needed for leakage-free splits. With four scenes the default assignment is two train, one validation, one test.

```bash
python -m training.prepare_dataset data/raw/scene_1 data/raw/scene_2 data/raw/scene_3 data/raw/scene_4
python -m training.train --manifest data/patches/manifest.csv --epochs 100 --batch-size 4
python -m training.train --manifest data/patches/manifest.csv --epochs 100 --resume checkpoints/latest_checkpoint.pth
python -m training.evaluate --manifest data/patches/manifest.csv --checkpoint checkpoints/best_generator.pth
python -m training.export_model --checkpoint checkpoints/best_generator.pth
```

To reconstruct a test mosaic:

```python
from app.services.inference_service import reconstruct_scene_mosaic

reconstruct_scene_mosaic(
    "data/patches/manifest.csv",
    "outputs/predictions",
    "LC09_L2SP_147047_20240201_20240208_02_T1",
    "outputs/geotiff/generated_rgb_geotiff.tif",
    "data/boundaries/maharashtra_districts.shp",
)
```

## Docker

```bash
cp .env.example .env
docker compose up --build
```

Backend: `http://localhost:8000`; frontend: `http://localhost:8501`. Data, outputs, and checkpoints are bind-mounted. The default image uses the PyPI Torch build and runs on CPU where CUDA is absent.

For NVIDIA GPU training, use a CUDA-enabled PyTorch base image, install a matching Torch wheel, install NVIDIA Container Toolkit, and add a Compose GPU device reservation. Confirm compatibility at runtime with `python -c "import torch; print(torch.cuda.is_available())"`.

## Troubleshooting

- **ST_B10 thermal band not found**: use a Collection 2 Level-2 surface-temperature product and preserve official filenames.
- **No valid paired patches**: inspect QA coverage, scene overlap/alignment, patch size, and minimum valid fraction.
- **Missing checkpoint**: train first or provide a compatible generator checkpoint.
- **FID unavailable**: use at least two held-out samples and ensure `torch-fidelity` can obtain Inception weights.
- **CUDA out of memory**: reduce batch size, use smaller inference tiles, or run on CPU.
- **Unsupported CRS**: ensure every raster and boundary has a valid CRS definition.
- **Docker cannot build GeoPandas/Rasterio**: use the supplied Python 3.11 image and confirm GDAL development packages are available.

## Limitations and Responsible Interpretation

Thermal-to-visible translation is underdetermined: many surface colors can correspond to similar temperatures. Cloud masking and district clipping reduce invalid support but do not remove seasonal, atmospheric, sensor, or geographic domain shift. FID is unstable on very small test sets. Reported values apply only to the held-out scenes evaluated by the current checkpoint and must not be presented as nationwide operational performance.
